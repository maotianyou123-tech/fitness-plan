01 · START WITH RECOVERY

先卸下疲劳，再建立长期节奏

常规卧推保留4×9、5×7、6×5、7×3。深蹲从100kg的5×5开始，硬拉从140kg的5×5开始；这些是待实际验证的起点，恢复与RPE决定能否执行。

2026-09-24 · 长期轮转

这次真正调整的三件事

  1. 卧推间隔拉到三个日历日。 卧推→下肢→休息。下肢交替深蹲和硬拉，四种卧推走完用12天。卧推仍有22组122次，平均每7天约12.8组，比原八天循环的19.3组低约三分之一。
  2. 热身必须保持低强度。 常规训练日六项、两轮、每项每轮25次，共12组300次，约15–25分钟。目标RPE3–4、至少还能轻松做约10次；若局部酸胀、动作走样或主项热身变沉，就减阻力或提前结束。
  3. 两轮常规训练后，安排恢复。 24天常规＋6天恢复，构成一个30天周期。你已报告疲劳，默认先加6天开局恢复。恢复段是明确的例外：减少主项组次，暂停300次热身和练后辅助，不凑训练量。

这是借鉴温宁低强度准备、分清主项与辅助的个人安排，没有照搬他的最大努力/动态努力体系。12×25不是额外的增肌任务，也不保证消除疲劳。长期执行依靠剂量、余力、恢复和记录一起调整。

02 · TWELVE DAYS, FOUR BENCH SESSIONS

训练与休息，一起排清楚

常规12天，完整走完卧推A—D

    六天的训练类型重复一次，卧推组次继续向前走：第1/4/7/10天依次A/B/C/D。额外休息只让后续顺延，不把下肢取消，也不把两次卧推挤到一起。

    训练表只为工作日建立记录，休息日不用打卡。重量是计划值；正常训练目标未达成时，系统会下调之后同类训练一档，历史保留原处方。

    03 · WARM-UP, MAIN LIFT, ASSISTANCE

    热身做准备，辅助做训练

    同一个动作可以有不同用途，区别在负荷、难度、数量和进阶目标。正式组前不把小肌群练到酸胀；正式组后，辅助才按余力渐进加重。

    顺序：轻活动3–5分钟 → 六项温宁式准备×两轮 → 休息3–5分钟 → 主项逐级递增热身 → 工作组 → 练后辅助。

    节奏：动作间可休20–40秒，轮间60–90秒；不计时抢速度。热身试探重量仅作找感觉的起点，25次若超过RPE4就减轻；自重动作也可能太重，应先降低难度。

    计数：每项每轮算1组。侧支撑与单腿伸膝第一轮左、第二轮右，每侧各25次，总共两组；交替核心动作是左右合计25次，不是每侧25次。完整一轮六项150次，两轮300次。

    恢复段：暂停这套12×25循环，只做轻活动和专项递增热身，练后辅助省略。这是降低总量的阶段，不用恢复训练去证明自己能做多少。

    05 · KEEP THE PLAN RECOVERABLE

    长期进步，需要停止加码的规则。

    日期决定训练顺序，表现决定重量。正常卧推组次固定；恢复段临时减量，不占用A—D的正常轮转。

    1. 起步校准
      连续疲劳时先恢复6天。

      默认开局卧推2×5和2×3，约用对应常规重量的80%；深蹲2×5、硬拉2×3约用70%，向下配片取整，RPE≤6。不做12×25及练后辅助。仍未恢复时继续延后，不因第7天到了就进入高容量。

    2. 主项上限
      卧推和深蹲≤RPE8，硬拉≤7.5。

      前几组应明显留有余力。首组就接近上限，后续减一档；重量降低仍明显吃力，提前结束。硬拉140kg五组五次是25次工作重复，如果近期没有完整做过，就按首轮实测难度校准，不能把140当成必须完成的数字。

    3. 按项进阶
      同类同重量连续两次达标，再考虑最小一档。

      器械2.5kg档距时要求全部组RPE≤7.5；5kg档距时要求≤7。卧推A/B/C/D、深蹲、硬拉分别判断，恢复段不计入。整周期结束、恢复正常后应用建议；数据不足或热身已造成疲劳就保持。

    4. 辅助进阶
      先把次数做稳，再小幅加重。

      同一辅助连续两次全部达到次数上限且仍保留目标余力，才加最小可用档位，再从次数下限做起。热身动作不使用这条追重规则。主项难度过高时先省略复合辅助，内收外展也不追力竭。

    5. 提前恢复
      同重量连续变难、反复欠次数、肩肘腰不适时及时调整。

      正常未达标会下调未来同类训练一档。整体恢复不佳可提前进入6天恢复段；归档当前记录后，从轻练重新开始。持续或反复疼痛停止相关训练并评估，不能靠增加热身组数解决。

    6. 周期回顾
      24天常规＋6天恢复是起始框架。

      具体减量时机来自本版编排，并非研究证明的最佳周期。睡眠不足、工作压力大或热身300次难以保持轻松时，应更早减量；长时间稳定轻松时也先看记录，不自动回到每轮强加5kg。

    02 / FATIGUE & FAILURE

    不把每组练到极限

    一项10名训练男性的卧推与深蹲研究发现，力竭方案比保留余力方案造成更大急性疲劳、恢复更慢。它支持保留余力的原则，不能推导你的准确恢复时间，也未测试本版温宁式热身。
