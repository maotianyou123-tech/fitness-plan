# 长期力量轮转：使用说明

更新：2026-09-25。

## 打开与分享

双击项目根目录的 `index.html`，浏览器直接打开，无需安装、服务器或联网。分享时发送 `健身计划.zip`，其中只有同一份 `index.html`，对方解压即可打开。页面样式、图片、脚本和可下载说明均内置；引用资料链接需要联网。

唯一维护目录是 `/home/k405/Desktop/fitness-plan`。根目录保留HTML、ZIP、README和“项目资料”；src是源码、docs是说明、scripts是构建、tests是测试，示例单独存放。GitHub自动部署配置位于隐藏的.github目录，不依赖原桌面目录。

## 这版的安排

常规训练按“卧推—深蹲—休息—卧推—硬拉引体—休息”重复。卧推四种组次依次4×9、5×7、6×5、7×3，12天完成一整轮。深蹲从100kg 5×5、硬拉从140kg 5×5试起。

默认先进行6天开局恢复，再24天常规、6天周期末恢复。之后以30天为基础重复；多休息则顺延。常规训练每次六项轻准备×两轮×25次，专项递增热身另算，辅助放在正式组后。恢复段明确减量，省略12×25和练后辅助。

完整动作、试探重量、休息与选择理由见 [重建计划与研究依据.md](重建计划与研究依据.md)，网页底部也可离线下载。

## 设置起点

1. 在“各主项独立设置”填写可靠单次TM、整根杠铃的最小总增量2.5/5kg、杆重和开始日期。TM已经是可靠单次，不再额外乘97%。
2. 如需重新估算，点击“按 TM 生成卧推参考起点”，会按65/70/75/80%向下取整，填入A/B/C/D四个输入框。只改变表单，点击保存才应用。深蹲、硬拉不随卧推TM改变。
3. 四种卧推及深蹲、硬拉均可独立修改。默认TM155、20kg杆、2.5kg档距时，卧推为100/107.5/115/122.5kg；这些只是疲劳后重新校准的暂定值。
4. 器械只有5kg总档距时，要把所有起点设为可实际装出的重量。比如107.5kg不能保留，应改为105kg等；网页不会悄悄改变你的手填值。
5. 默认勾选开局恢复。确实已经恢复时，可以在尚未记录训练前取消。已有主项记录后不能切换这一项，以免错配历史。
6. 点击保存。未来处方更新，已经完成的训练保留当时的重量、组次与杆重。

只改TM不会自动覆盖手填起点，也不自动提高下一周期重量。要重算请明确点击参考值按钮。

## 按顺序完成当天训练

“继续本次训练”跳到第一个还未完成的主项。完整表和选择框可预览未来训练；预览不会推进进度，未来主项不能提前提交。

当天卡片按实际顺序展示：低强度准备 → 专项递增热身 → 主项 → 练后辅助。每个热身和辅助动作都可以填写实际阻力、次数等。热身另填0–2组，空白代表没记录，0代表省略；每项计划2组，共12组。单侧动作和交替动作按卡片计数，不翻倍。

热身、辅助和笔记输入后自动保存。它们不决定主项是否完成，也不因为保存了主项而自动标成已做。主项保存后仍能补充这些内容。

## 主项怎么记录

- 每组填实际含杆重量、次数和RPE。没做的组填0次，RPE留空；不要为了表格完成度补组。
- 确认“动作标准一致”时，才勾选对应选项。
- “准备后的感受”记录热身是否让你发沉或酸胀；两次加重成绩中有这种记录，就不会建议加重。
- “正常训练”允许保存没完成或超RPE的结果。只要做过工作组，本日可结束，但未达标会下调未来同类主项一个器械档位。
- “明显疲劳/疼痛暂停”保留记录，不把本日标成完成。参考日期至少延后两天，恢复不够可继续延后；这不代表疼痛后两天就适合训练。
- 日期不能在未来，后续实际记录须遵守既定间隔。卧推后通常次日下肢，下肢后休一天；额外休息会一起计入。

完成主项后点击“查看下一次安排”。进度只统计主项记录，不代表已经做完所有辅助。

## 休息、加重和开启下一周期

本次卡片可勾选额外休息一天，后续日期自动顺延，历史实际日期不改。下一次实际晚到时，按真实日期填写，后面的日期会跟着走。已有后续主项记录的旧训练日不再修改其额外休息。

重量不按每周或每轮统一加5kg。六个主项分别看最近两次同类、同组次、同重量的常规记录：全部达标、准备后无疲劳，2.5kg档要求每组RPE≤7.5，5kg档要求≤7。恢复段不计入。

整个周期包括末尾恢复全部记录完成后，“恢复正常，按建议开始下一周期”才可用。点击即归档当前周期，按各项建议建立新周期；仍然疲劳时先不点击，多休息。需要手动保守调整时可以在设置区改未来起点。

常规阶段整体恢复不好时，可点击“提前进入6天恢复段”：保留当前记录，重量只保持或降低，重新安排6天恢复＋24天常规＋6天恢复。不要反复开启恢复以追求完成次数，正在恢复时直接延后训练。

## 数据、导出与打印

- 数据保存在当前浏览器的本地存储。尽量持续使用同一个浏览器、同一目录的 `index.html`；移动文件、更换浏览器、清除站点数据或隐私模式可能无法读取原记录。
- 新版独立存储；能访问的旧版训练记录只读保留，不作为新版加重依据，不删除你的历史。旧版源码备份与个人历史记录不是同一件事。
- “下载完整训练表CSV”包含本周期日期、处方、热身、专项准备、辅助、当前实际记录和笔记，可用表格软件打开。以UTF-8导出，带中文编码标记。CSV是导出表，不是导入格式。
- “导出全部记录JSON”包含当前周期、归档周期、辅助热身记录、笔记以及浏览器中可访问的旧版数据。当前页面不提供JSON导入按钮；需要迁移恢复时，可让维护者根据该文件处理。
- “打印训练表”支持浏览器打印或另存PDF，包含完整主项表和热身辅助模板；打印时动作明细自动展开。建议A4横向、100%比例，不为省纸缩小到看不清。
- `项目资料/示例` 是参考TM155、2.5kg档距的全新空白计划示例，未包含你的个人训练记录。
- HTML和ZIP本身不携带浏览器里的个人记录；分享ZIP不会自动发送训练历史。主动导出的CSV/JSON可能含个人笔记，分享前看清内容。

网页全局最小字号维持16px，保留当前风格。手机宽度不超过760px时，底部显示“首页、计划、训练、记录、更多”；各分区单独显示，避免长页面反复滚动。设置起点、热身辅助、恢复规则和参考资料在“更多”里。

手机版计划按阶段折叠；训练页提供“热身、上杠、主项、辅助”四步跳转。当天动作、剂量和提示始终列出；每项热身和辅助的输入区点击“填写记录”展开。主项仍按组填写重量、次数、RPE。数字字段优先使用数字或小数键盘，页面切换保留当前DOM中的未提交输入；刷新页面前仍需保存主项。

手机右上角“分享”在网站部署后提供复制网址和浏览器支持的系统分享；本地打开时提示发送HTML或ZIP。电脑也可在“参考与说明”找到分享入口。电脑和手机使用同一个HTML，无需单独维护手机站。

网站入口为 https://maotianyou123-tech.github.io/fitness-plan/ ，更新与自动发布步骤见 [GitHub发布说明.md](GitHub发布说明.md)。线上网址、电脑本地文件和不同手机浏览器的记录不会自动同步；每个访问者独立记录。
